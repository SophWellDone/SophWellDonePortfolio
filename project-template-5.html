Overview/Goal

I worked as a contractor on Ella-Stick, a game that is developed with the Nintento Switch DevKit for release for the Switch console on the Nintendo Store. I was contracted as a level designer for 42 hours. In that time, I worked with a Producer, Project Advisor and the rest of the team to work through assigned tasks.

Contribution Breakdown

Tutorial & Hub Level

My first task was to create a hub world that acted as a tutorial. I submited my first draft quickly to get feedback as soon as possible.

Environmental Props

Afterwards I was given the task of making 3 environment assets - Bush, grass and shrubbery - with a shared UV map and material set.

  • Make a high poly version of a fern-like leaf, clover-like leaf and grass
  • Bake them onto a plane and create an appealing, cartoony set of maps in Substance Painter
  • Use the planes to create highly optimised models.
